# Benchmark Methodology & Guide

This document describes the methodology used to calculate the TokenGuardian performance stats and details how you can run benchmarks in your own development environment.

---

## 📐 Benchmark Metrics

We measure performance using three primary metrics:
1. **Output Token Count**: The total number of tokens generated by the model. (Primary optimization target).
2. **Execution Latency**: Time in seconds from request submission to completed response. (Fewer tokens generate faster).
3. **Accuracy / Completeness Rating**: Evaluated on a scale of 1-5 to ensure optimization does not degrade utility.

---

## 🏃 How to Run the Benchmarks

### 1. Manual Comparison (Claude Console)
The easiest way to benchmark is using the **Anthropic Console**:

1. Navigate to the [Anthropic Console Workbench](https://console.anthropic.com/workbench).
2. Create a new Prompt.
3. In the **System Prompt** section, paste the contents of `SKILL.md`.
4. In the **User Message**, write your query and config block.
5. Run the query, and note the token counts in the bottom right corner (Input/Output).
6. Clear the system prompt, run the same query again, and compare the results.

---

### 2. Automated CLI Benchmarking Script
You can write a simple Python script to automate benchmarking. Here is a template using the `anthropic` client:

```python
import time
import os
import json
import anthropic

client = anthropic.Anthropic(api_key=os.environ.get("ANTHROPIC_API_KEY"))

# Test query
query = "Write a python function to validate an email address using regex."

def run_test(system_prompt=None):
    start_time = time.time()
    response = client.messages.create(
        model="claude-3-5-sonnet-20241022",
        max_tokens=1000,
        system=system_prompt if system_prompt else "",
        messages=[{"role": "user", "content": query}]
    )
    latency = time.time() - start_time
    
    return {
        "tokens_input": response.usage.input_tokens,
        "tokens_output": response.usage.output_tokens,
        "latency": latency,
        "content": response.content[0].text
    }

# Read TokenGuardian prompt
with open("SKILL.md", "r", encoding="utf-8") as f:
    tg_prompt = f.read()

print("Running baseline test...")
baseline = run_test(system_prompt="")

print("Running TokenGuardian test...")
optimized = run_test(system_prompt=tg_prompt)

# Report results
print("\n--- RESULTS ---")
print(f"Baseline Output Tokens: {baseline['tokens_output']} (Latency: {baseline['latency']:.2f}s)")
print(f"Optimized Output Tokens: {optimized['tokens_output']} (Latency: {optimized['latency']:.2f}s)")
saved = baseline['tokens_output'] - optimized['tokens_output']
percent_saved = (saved / baseline['tokens_output']) * 100
print(f"Token Savings: {saved} tokens ({percent_saved:.1f}% reduction)")
```
