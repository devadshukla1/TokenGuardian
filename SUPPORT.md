# Support Guidelines

We want to ensure you have the best experience using TokenGuardian. This document details how to get help, ask questions, and troubleshoot integration issues.

---

## 🔍 Self-Service Support

Before reaching out for help, please review these resources, which cover the most common issues:
1. **[FAQ](file:///docs/FAQ.md)**: Frequently asked questions about prompt caching, compatibility, and LLM behavior.
2. **[Troubleshooting Guide](file:///docs/Troubleshooting.md)**: Common failure modes, prompt drift, and instructions on how to force Claude to adhere to the config.
3. **[Configuration Docs](file:///docs/Configuration.md)**: Details on adjusting verbosity, style parameters, and output budgets.

---

## 💬 Community Channels

If you can't find the answers in the documentation, please use the following community spaces:

* **GitHub Discussions**: Best for general questions, sharing custom configurations, showing off token savings, or discussing roadmap features.
* **GitHub Issues**: Best for reporting reproducible bugs, system prompt leaks, or submitting technical feature requests.

---

## 🚨 Security & Prompt Leaks

If you have discovered a security issue, prompt injection vulnerability, or a method to bypass TokenGuardian, please do not create a public issue. Follow our **[Security Policy](file:///SECURITY.md)** and email **security@tokenguardian.org**.

---

## 🤝 Commercial Support

If your organization is looking to deploy TokenGuardian at scale or requires custom prompt optimization and training:
* Custom MCP server integrations.
* Token budgeting for production agent fleets.
* Enterprise SLAs and dedicated tuning.

Please contact our enterprise team at **enterprise@tokenguardian.org** to discuss your requirements.
